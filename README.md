# Spec Studio plugin SDK

The protocol between Spec Studio (the app and the relay) and a backend plugin, a TypeScript SDK to write a plugin, and the conformance tests that every plugin runs.

The official plugins:

- [plugin-json](https://github.com/spec-studio-app/plugin-json): JSON files. The default.
- [plugin-temporal](https://github.com/spec-studio-app/plugin-temporal): Temporal, with history and replay.
